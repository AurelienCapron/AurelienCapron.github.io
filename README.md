## Technologies et organisation

Le portfolio est un **site statique en HTML, CSS et JavaScript**, hébergé avec **GitHub Pages**. Il ne nécessite ni serveur applicatif ni base de données. L’application Flask présentée dans le projet Backyard est un projet distinct : elle n’est pas exécutée par le portfolio.

Les styles utilitaires issus de Tailwind CSS sont **précompilés et intégrés aux pages** : aucun compilateur Tailwind n’est chargé dans le navigateur. Les styles spécifiques restent dans les pages, tandis que les règles partagées de progression, d’affichage des médias et de navigation sont regroupées dans `assets/site-media.css`.

| Emplacement | Rôle |
| --- | --- |
| `index.html` | Accueil : présentation, compétences, projets, parcours, loisirs et contact. |
| `telecommande.html`, `amplificateur.html`, `tipe.html`, `domethic.html`, `poulailler.html`, `backyard.html` | Pages des six projets techniques. |
| `sacha-heritage.html`, `bds.html`, `judo.html`, `perouges.html`, `saxhorn.html` | Pages des cinq loisirs et engagements. |
| `assets/projets/<projet>/` | Images, vidéos, documents et modèles associés à chaque projet. |
| `assets/hobbies/<activite>/` | Médias et documents associés à chaque loisir. |
| `assets/fonts/` | Polices locales. |
| `assets/site-media.css` | Styles communs des médias, de la progression et de la navigation. |
| `assets/site-media.js` | Chargement des images et des vidéos, gestion des erreurs et solutions de repli. |
| `assets/site-experience.css` | Sommaires, bilans, acquis et liens entre les pages. |
| `assets/site-experience.js` | Preuves de compétences, suivi du sommaire et contact contextualisé. |
| `assets/licenses/tailwindcss.txt` | Licence des styles utilitaires Tailwind CSS. |
| `assets/CV_Aurelien_Capron.pdf`, `assets/CV_Aurelien_Capron_EN.pdf` | CV proposés sur le site. |

Les icônes du site, l’image de partage et la photo de présentation restent des ressources communes. Les médias propres à une activité sont rangés dans son sous-dossier.

## Consulter le site en local

Depuis la racine du dépôt, avec Python 3 :

```bash
python3 -m http.server 8000
```

Ouvrir ensuite **http://localhost:8000**. Aucune installation npm ni compilation préalable n’est nécessaire pour servir les fichiers existants.

Le visualiseur 3D des pages concernées est chargé à la demande et nécessite l’accès à sa ressource externe. Les liens vers les réseaux sociaux, les vidéos YouTube et les autres sites nécessitent également une connexion Internet.

## Mise à jour et documentation

Les contenus et leurs traductions sont définis dans les pages HTML. Lors d’une modification, conserver la correspondance entre les textes français et les clés du dictionnaire anglais. Les numéros des clés de cartes identifient les activités ; ils ne déterminent pas leur position dans les carrousels.

Les styles étant précompilés, une nouvelle classe utilitaire doit disposer d’une règle dans le CSS livré : elle ne sera pas générée automatiquement au chargement de la page.

Les en-têtes distinguent la documentation d’un fichier de son origine. La date de documentation n’est pas une date de création ; lorsque l’historique Git est disponible, il permet d’identifier la première version enregistrée dans le dépôt. La date de création réelle reste non renseignée si elle ne peut pas être vérifiée.

Conserver la licence Tailwind avec les styles distribués. Les bibliothèques, marques, articles et visuels de tiers conservent leurs droits et attributions respectifs ; leur présence dans le portfolio ne leur attribue pas la licence du code du site.
